## 2. 説明文（description）

### プロモーション用テキスト（App Store・170字以内）
> App Store と Google Play のレビューを一箇所で監視。AIが返信文案を提案し、そのままストアへ投稿。評価の推移も可視化して、個人開発でもレビュー対応を後回しにしない。

### 概要（本文）
```
RevPilot は、個人開発者のためのアプリレビュー管理ツールです。

■ レビューをまとめて監視
App Store と Google Play のレビューを一つの受信箱に集約。新着を見逃しません。

■ AIが返信を下書き
レビューの内容とトーンに合わせて、AIが返信文案を生成。確認して、そのままストアへ投稿できます。

■ 一括返信で時間短縮
たまったレビューにまとめて返信（プランに応じて件数が拡大）。

■ 評価を分析
星の分布や推移、よく出るトピックをアプリ別・ストア別に可視化。

■ プラン
・Free … アプリ1件 / AI返信 月5件 / 1件ずつ返信 / 自動取得 毎時
・Pro（月額¥1,480）… アプリ5件 / AI返信 月500件 / 一括返信 最大20件 / 自動取得 毎時
・Max（月額¥2,980）… アプリ無制限 / AI返信 無制限（公正利用 月2,000件）/ 全レビュー一括返信 / 自動取得 毎時

※価格は税込。サブスクは自動更新されます。解約はいつでも可能です。
```

## 3. 自動更新サブスクの表記（両ストア必須）

課金導線とメタデータに以下を明記すること（Apple は特に厳格）:

- 各プラン名・期間（月額）・価格
- 「支払いは購入確定時に Apple ID / Google アカウントに請求されます」（IAP採用時）
- 「解約しない限り期間終了時に自動更新されます」
- 「更新は現在の期間終了の24時間前までに解約可能」
- 利用規約・プライバシーポリシーへのリンク

> ⚠️ 現状のモバイル決済は **Stripe（アプリ内ブラウザ）** 方式。iOS のデジタルサブスクは
> 原則 IAP 必須（App Store Review 3.1.1）で、**iOS 審査でリジェクトの可能性が高い**。
> iOS 申請前に IAP（例: RevenueCat）対応を再検討すること。詳細はメモ `app-store-iap-caveat`。
> Android（Google Play）も Play 課金ポリシーに留意。

## 4. データ安全性の申告

### Apple — App Privacy（収集データの申告）
| データ種別 | 収集 | 用途 | 個人と紐付け |
|---|---|---|---|
| メールアドレス | あり | アプリ機能 / アカウント | あり |
| ユーザーコンテンツ（レビュー・返信文） | あり | アプリ機能 | あり |
| 購入・課金情報 | あり（Stripe/ストア） | アプリ機能 | あり |
| 診断・利用状況 | あり | 分析 / 品質改善 | 任意 |

- トラッキング（ATT）: **なし**（広告目的の追跡はしていない）

### Google Play — データセーフティ
- 収集: メールアドレス、アプリ内アクティビティ、アプリの操作情報
- 目的: アプリの機能、アカウント管理、分析
- 送信時の暗号化: あり（HTTPS）
- 保存データの扱い: ストア資格情報は暗号化して保管
- ユーザーによる削除リクエスト: 可（退会で削除）

> 第三者処理者として Supabase / Stripe / Anthropic(Claude) / Apple / Google を利用し、
> 一部は国外移転を伴う旨をプライバシーポリシーに記載済み。
